# ebd bn'b

The project we build in the BINF 503 (Electronic Business Development) labs at GIU,
one branch per finished lab. Pick a branch, then **Code → Download ZIP**.

| Branch | Where it ends |
|---|---|
| `lab-03` | npm, Express, two `GET` routes |
| `lab-04` | The full REST API, on an in-memory array |
| `lab-05` | The API on MongoDB Atlas, in one file |
| `lab-05-part2` | The same API, split into `db.js`, `models/`, `controllers/`, `routes/` |
| `lab-06` | `backend/` (Lab 5, Part 2) and a React front end in `frontend/` |
